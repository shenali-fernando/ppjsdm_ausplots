# ppjsdm_ausplots
This repo contains the analysis on the TERN ausplots data using the saturated parwise interaction Gibbs point process (ppjsdm) model.

The file structure is so that code for functions and exploratory analysis are found in the 'code' folder. Code, vignettes, and outputs for different model specifications (i.e. changing how individuals are grouped) are gound in the 'specification' folder.
